  c.png       -> C
  java.png    -> Java
  python.png  -> Python
  ai.png      -> AI

Recommended size: 128x128 or 256x256, transparent background.
Once added, the dashboard "Recommended for You" cards will show these logos
automatically (matched by course title). Tap still opens /course/[id].
